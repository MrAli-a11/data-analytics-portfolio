# 📊 45-Days Data Analyst Job-Ready Roadmap (Nov 17 – Dec 31, 2026)

A disciplined, 4-hour daily execution sprint (**1 hr Morning Retention + 3 hrs Evening Implementation**) focused on mastering high-ROI Data Analytics tools, solving real business problems, and building end-to-end projects.

---

## 🎯 Priority Stack & Weightage
1. **SQL (45%)** — Query optimization, Joins, CTEs, Window Functions & LeetCode SQL 50.
2. **Power BI & Excel (35%)** — Power Query, Star Schema Data Modeling, DAX, Interactive Dashboards & Advanced Excel.
3. **Python & Pandas (20%)** — Data Cleaning, Manipulation & Exploratory Data Analysis (EDA).

---

## ⏱️ Daily Routine Blueprint
* **Morning (6:00 AM – 7:00 AM):** 15m Active Recall (No screen) + 45m LeetCode SQL 50 / Practice.
* **Evening (7:00 PM – 10:00 PM):** 45m Concept + 15m Break + 75m Hands-on Dataset Implementation + 15m Break + 30m Error Logging & GitHub Push.
